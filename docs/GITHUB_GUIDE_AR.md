# رفع VibeSense على GitHub خطوة بخطوة

## الطريقة الأسهل (من المتصفح)
1. ادخلي على github.com وسجلي دخول.
2. اضغطي علامة + فوق ثم New repository.
3. الاسم: vibesense
4. الوصف (Description): Predictive maintenance from vibration, built for a tiny chip. Simulated data.
5. اختاري Public. لا تحطين علامة على Add README لأن عندنا واحد.
6. اضغطي Create repository.
7. اضغطي رابط uploading an existing file.
8. فكي الملف المضغوط على جهازك، واسحبي كل اللي داخل مجلد vibesense للصفحة.
   مهم: المجلد المخفي .github لازم يطلع معهم. على الماك اضغطي Command + Shift + نقطة لإظهار الملفات المخفية.
9. اكتبي بخانة Commit: Initial commit
10. اضغطي Commit changes.

## بعد الرفع
1. فوق يمين الصفحة اضغطي الترس جنب About وحطي Topics:
   predictive-maintenance, tinyml, esp32, vibration-analysis, streamlit, python, embedded
2. من Settings ثم General، تحت Social preview، ارفعي assets/banner.png.
3. اضغطي Pin على المستودع من صفحة حسابك (Customize your pins).
4. تأكدي إن علامة الاختبارات (Actions) طلعت خضراء.

## قبل ما تنشرين
- افتحي README من المتصفح وتأكدي إن الصور ظاهرة.
- ما في أي مفتاح سري بالمشروع، ما تحتاجين تحطين شي.
- كلمة "محاكاة" لازم تبقى واضحة بالوصف والمنشور.
